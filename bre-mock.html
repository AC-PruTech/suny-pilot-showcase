How this maps to Salesforce BRE

Atlas table → Expression Set + Decision Table → Apex BreDecisionService → IBreEngine → outcome stored as BRE_Decision__c / BRE_Reason__c / BRE_Rule_Version__c on Order (also last-evaluated on Product2). Funding record, when routed, is PSS_State_Payment__c placeholder with Record Types Employer_Sponsored / Degree_Financial_Aid / State_Workforce_Funding. Confirm license/API in-org: BRE license/entitlement, Expression Set availability/naming and the exact Apex/Flow/LWC invocation method must be confirmed in-org — this mock runs no org call (see BRE-DESIGN.md §2, §10).
